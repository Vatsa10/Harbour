Помимо `dev`, `dev:build`, `dev:add` и `dev:typecheck`, CLI `yarn searm` предоставляет команды для выполнения функций, просмотра логов и управления установками приложений.

## Выполнение функций (`yarn searm dev:function:exec`)

Запустите логическую функцию вручную, не вызывая её через HTTP, cron или событие базы данных:

```bash filename="Terminal"
# Execute by function name
yarn searm dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn searm dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn searm dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn searm dev:function:exec --postInstall
```

## Просмотр логов функций (`yarn searm dev:function:logs`)

Потоковая передача журналов выполнения логических функций вашего приложения:

```bash filename="Terminal"
# Stream all function logs
yarn searm dev:function:logs

# Filter by function name
yarn searm dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn searm dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Это отличается от `yarn searm docker:logs`, который показывает логи контейнера Docker. `yarn searm dev:function:logs` показывает журналы выполнения функций вашего приложения с сервера SeaRM.
</Note>

## Генерация типизированного клиента (`yarn searm dev:generate-client`)

Повторно сгенерируйте типизированный API‑клиент (`searm-client-sdk`) из схемы активного удалённого экземпляра, не выполняя сборку или синхронизацию приложения. Используйте это, чтобы получить типизированного клиента в любом проекте — например, в backend‑сервисе в отдельном репозитории — который взаимодействует с вашим экземпляром SeaRM:

```bash filename="Terminal"
# In your project (no SeaRM app definition required)
yarn add searm-sdk searm-client-sdk

# Connect to the SeaRM instance to generate the client from
yarn searm remote:add

# Generate the typed client into node_modules/searm-client-sdk
yarn searm dev:generate-client
```

Затем импортируйте клиента в свой код:

```typescript
import { CoreApiClient } from 'searm-client-sdk/core';
```

Повторно запустите команду при каждом изменении вашей модели данных, чтобы обновить сгенерированные типы.

<Note>
Клиент генерируется внутри `node_modules`, поэтому он не добавляется в ваш репозиторий вместе с кодом. Запускайте `yarn searm dev:generate-client` после каждой установки (например, в скрипте `postinstall` или в CI).
</Note>

## Удаление приложения (`yarn searm app:uninstall`)

Удалите свое приложение из активного рабочего пространства:

```bash filename="Terminal"
yarn searm app:uninstall

# Skip the confirmation prompt
yarn searm app:uninstall --yes
```

## Управление удалёнными серверами

**Remote** — это сервер SeaRM, к которому подключается ваше приложение. Во время настройки скаффолдер автоматически создаст его для вас. Вы можете в любой момент добавлять новые удалённые серверы или переключаться между ними.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn searm remote:add

# Connect to a local SeaRM server (auto-detects port 2020 or 3000)
yarn searm remote:add --local

# Add a remote non-interactively (useful for CI)
yarn searm remote:add --url https://your-searm-server.com --api-key $SEARM_API_KEY --as my-remote

# List all configured remotes
yarn searm remote:list

# Set the active remote
yarn searm remote:use <name>
```

Ваши учётные данные хранятся в `~/.searm/config.json`.
