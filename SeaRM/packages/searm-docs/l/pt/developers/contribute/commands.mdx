---

Os comandos podem ser executados a partir da raiz do repositório usando `npx nx`. Use `npx nx run {project}:{command}` para direcionar explicitamente.

## Iniciando o aplicativo

```bash
npx nx start searm-front          # Frontend dev server (http://localhost:3001)
npx nx start searm-server         # Backend server (http://localhost:3000)
npx nx run searm-server:worker    # Background worker
```

## Banco de Dados

```bash
npx nx database:reset searm-server                          # Reset and seed database
npx nx run searm-server:database:migrate:prod               # Run migrations
npx nx run searm-server:database:migrate:generate --name <name> --type <fast|slow>  # Generate a migration
```

## Linting

```bash
npx nx lint:diff-with-main searm-front    # Lint changed files (fastest)
npx nx lint:diff-with-main searm-server
npx nx lint searm-front --configuration=fix  # Auto-fix
```

## Verificação de tipos

```bash
npx nx typecheck searm-front
npx nx typecheck searm-server
```

## Testes

```bash
# Frontend
npx nx test searm-front                          # Jest unit tests
npx nx storybook:build searm-front               # Build Storybook
npx nx storybook:test searm-front                # Storybook tests

# Backend
npx nx run searm-server:test:unit                # Unit tests
npx nx run searm-server:test:integration         # Integration tests
npx nx run searm-server:test:integration:with-db-reset  # Integration with DB reset

# Single file (fastest)
npx jest path/to/test.test.ts --config=packages/{project}/jest.config.mjs
```

## GraphQL

```bash
npx nx run searm-front:graphql:generate                        # Regenerate types
npx nx run searm-front:graphql:generate --configuration=metadata  # Metadata schema
```

## Traduções

```bash
npx nx run searm-front:lingui:extract   # Extract strings
npx nx run searm-front:lingui:compile   # Compile translations
```

## Compilação

```bash
npx nx build searm-shared   # Must be built first
npx nx build searm-front
npx nx build searm-server
```
