`yarn searm` CLI は、アプリ関連のすべてを操作するためのインターフェースです。 コマンド一覧:

| コマンド                                            | 機能                                                             | 参照ドキュメント                                                                                           |
| ----------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `dev`                                           | ソースファイルを監視し、変更をライブ同期します                                        | [クイックスタート](/l/ja/developers/extend/apps/getting-started/quick-start)                                    |
| `plan`                                          | メタデータの変更を適用せずにプレビュー                                            | [Syncing & recovery](/l/ja/developers/extend/apps/operations/sync-and-recovery#previewing-changes-plan) |
| `apply`                                         | プランを表示した後にメタデータの変更を適用                                          | [Syncing & recovery](/l/ja/developers/extend/apps/operations/sync-and-recovery)                         |
| `dev:build`                                     | アプリをコンパイルし、API クライアントを生成します（`.tgz` にパッケージするには `--tarball` を使用） | [公開](/l/ja/developers/extend/apps/operations/publishing)                                                |
| `dev:typecheck`                                 | TypeScript の型チェックを実行                                           | [テスト](/l/ja/developers/extend/apps/operations/testing)                                                  |
| `dev:add`                                       | 新しいエンティティのスキャフォールドを作成                                          | [スキャフォールディング](/l/ja/developers/extend/apps/getting-started/scaffolding)                                 |
| `dev:generate-client`                           | 型付き API クライアントを再生成                                             | このページ                                                                                              |
| `dev:function:exec` / `dev:function:logs`       | 関数を実行し、そのログをストリーミング                                            | このページ                                                                                              |
| `dev:translations-extract`                      | 翻訳可能な文字列を `locales/` カタログに抽出                                   | [翻訳](/l/ja/developers/extend/apps/translations/overview)                                                |
| `dev:catalog-sync`                              | マーケットプレイスのカタログ同期をトリガー                                          | [公開](/l/ja/developers/extend/apps/operations/publishing#how-marketplace-discovery-works)                |
| `app:publish` / `app:install` / `app:uninstall` | リリースライフサイクル                                                    | [公開](/l/ja/developers/extend/apps/operations/publishing) とこのページ                                         |
| `docker:*`                                      | ローカルの SeaRM サーバーコンテナを管理                                       | [ローカルサーバー](/l/ja/developers/extend/apps/getting-started/local-server)                                   |
| `remote:*`                                      | サーバー接続を管理                                                      | このページ                                                                                              |

すべてのコマンドは、デフォルトではない特定のリモートを対象にするために `-r, --remote \<name>` を受け付けます。

## 関数の実行（`yarn searm dev:function:exec`）

HTTP、cron、データベースイベントを介さずに、ロジック関数を手動で実行します：

```bash filename="Terminal"
# Execute by function name
yarn searm dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn searm dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn searm dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the install and uninstall hooks
yarn searm dev:function:exec --postInstall
yarn searm dev:function:exec --preInstall
yarn searm dev:function:exec --uninstall
```

## 関数ログの表示（`yarn searm dev:function:logs`）

アプリのロジック関数の実行ログをストリーミング表示します：

```bash filename="Terminal"
# Stream all function logs
yarn searm dev:function:logs

# Filter by function name
yarn searm dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn searm dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
これは Docker コンテナのログを表示する `yarn searm docker:logs` とは異なります。 `yarn searm dev:function:logs` は、SeaRM サーバーからアプリの関数実行ログを表示します。
</Note>

## 型付きクライアントを生成する（`yarn searm dev:generate-client`）

アプリをビルドしたり同期したりすることなく、アクティブなリモートのスキーマから型付き API クライアント（`searm-client-sdk`）を再生成します。 これを使用すると、別リポジトリにあるバックエンドサービスのような、SeaRM インスタンスと通信する任意のプロジェクトで型付きクライアントを取得できます：

```bash filename="Terminal"
# In your project (no SeaRM app definition required)
yarn add searm-sdk searm-client-sdk

# Connect to the SeaRM instance to generate the client from
yarn searm remote:add

# Generate the typed client into node_modules/searm-client-sdk
yarn searm dev:generate-client
```

次に、クライアントをコードでインポートします：

```typescript
import { CoreApiClient } from 'searm-client-sdk/core';
```

データモデルが変更されるたびにコマンドを再実行して、生成された型を更新してください。

<Note>
クライアントは `node_modules` 内に生成されるため、コードと一緒にはコミットされません。 インストールのたびに（たとえば `postinstall` スクリプトや CI で）`yarn searm dev:generate-client` を実行してください。
</Note>

## アプリのアンインストール（`yarn searm app:uninstall`）

アクティブなワークスペースからアプリを削除します：

```bash filename="Terminal"
yarn searm app:uninstall

# Skip the confirmation prompt
yarn searm app:uninstall --yes
```

## リモートの管理

**remote** とは、アプリが接続する SeaRM サーバーのことです。 セットアップ中に、スキャフォルダーが自動的にリモートを作成します。 リモートはいつでも追加や切り替えができます。

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn searm remote:add

# Connect to a local SeaRM server (auto-detects port 2020 or 3000)
yarn searm remote:add --local

# Add a remote non-interactively (useful for CI)
yarn searm remote:add --url https://your-searm-server.com --api-key $SEARM_API_KEY --as my-remote

# List all configured remotes
yarn searm remote:list

# Set the active remote
yarn searm remote:use <name>

# Check that the active remote's authentication is still valid
yarn searm remote:status

# Remove a remote
yarn searm remote:remove <name>
```

認証情報は `~/.searm/config.json` に保存されます。
