## Über die Community-Einstellungen

Im Bereich Community können Sie Early-Access-Funktionen aktivieren, bevor sie allgemein verfügbar sind, sowie nach SeaRM-Partnern suchen.

## Early-Access-Funktionen

Early-Access-Funktionen sind Funktionen, die vor der allgemeinen Verfügbarkeit noch getestet werden.

**Derzeit im Early Access:**

* **Verknüpfungsbeziehungen** — Viele-zu-viele-Beziehungen

### So aktivieren Sie Early-Access-Funktionen

1. Gehen Sie zu **Einstellungen → Community**
2. Navigieren Sie zum Bereich **Funktionen**
3. Suchen Sie die Funktion, die Sie aktivieren möchten
4. Aktivieren Sie sie
5. Die Funktion ist sofort verfügbar

<Note>
Early-Access-Funktionen können sich je nach Nutzerfeedback ändern. Ihr Feedback hilft uns, SeaRM zu verbessern!
</Note>

## Feedback zu Funktionen

Ihr Feedback hilft, SeaRM zu verbessern:

* Melden Sie Probleme mit Early-Access-Funktionen
* Teilen Sie mit, wie Sie neue Funktionen nutzen
* Schlagen Sie Verbesserungen über den [Community-Discord](https://discord.gg/cx5n4Jzs57) vor
