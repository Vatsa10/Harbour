بدلًا من إنشاء ملفات الكيانات يدويًا، استخدم أداة القوالب التفاعلية:

```bash filename="Terminal"
yarn searm dev:add
```

ستطلب منك اختيار نوع الكيان وتُرشدك عبر الحقول المطلوبة، ثم تُنشئ ملفًا جاهزًا للاستخدام يحتوي على `universalIdentifier` ثابت واستدعاء `defineEntity()` الصحيح.

يمكنك أيضًا تمرير نوع الكيان مباشرة لتخطي المطالبة الأولى:

```bash filename="Terminal"
yarn searm dev:add object
yarn searm dev:add logicFunction
yarn searm dev:add frontComponent
```

## أنواع الكيانات المتاحة

| نوع الكيان               | أمر                                      | الملف المُولَّد                                         |
| ------------------------ | ---------------------------------------- | ------------------------------------------------------- |
| كائن                     | `yarn searm dev:add object`             | `src/objects/\<name>.ts`               |
| الحقل                    | `yarn searm dev:add field`              | `src/fields/\<name>.ts`                |
| دالة منطقية              | `yarn searm dev:add logicFunction`      | `src/logic-functions/\<name>.ts`       |
| مكوّن أمامي              | `yarn searm dev:add frontComponent`     | `src/front-components/\<name>.tsx`     |
| دور                      | `yarn searm dev:add role`               | `src/roles/\<name>.ts`                 |
| مهارة                    | `yarn searm dev:add skill`              | `src/skills/\<name>.ts`                |
| وكيل                     | `yarn searm dev:add agent`              | `src/agents/\<name>.ts`                |
| عرض                      | `yarn searm dev:add view`               | `src/views/\<name>.ts`                 |
| عنصر قائمة التنقّل       | `yarn searm dev:add navigationMenuItem` | `src/navigation-menu-items/\<name>.ts` |
| تخطيط الصفحة             | `yarn searm dev:add pageLayout`         | `src/page-layouts/\<name>.ts`          |
| علامة تبويب تخطيط الصفحة | `yarn searm dev:add pageLayoutTab`      | `src/page-layout-tabs/\<name>.ts`      |
| عنصر قائمة الأوامر       | `yarn searm dev:add commandMenuItem`    | `src/command-menu-items/\<name>.ts`    |
| حقل العرض                | `yarn searm dev:add viewField`          | `src/view-fields/\<name>.ts`           |
| موفر الاتصال             | `yarn searm dev:add connectionProvider` | `src/connection-providers/\<name>.ts`  |

## ما الذي تُنشئه أداة القوالب

لكل نوع كيان قالب خاص به. على سبيل المثال، يسأل `yarn searm dev:add object` عن:

1. **الاسم (مفرد)** — مثل `invoice`
2. **الاسم (جمع)** — مثل `invoices`
3. **التسمية (مفرد)** — تُستمد تلقائيًا من الاسم (مثل `Invoice`)
4. **التسمية (جمع)** — تُملأ تلقائيًا (مثل `Invoices`)
5. **إنشاء عرض وعنصر تنقّل؟** — إذا أجبت بنعم، فستُنشئ أداة القوالب أيضًا عرضًا مطابقًا ورابط شريط جانبي للكائن الجديد.

أنواع الكيانات الأخرى لها مطالبات أبسط — فمعظمها يطلب اسمًا فقط.

نوع الكيان `field` أكثر تفصيلاً: يطلب اسم الحقل وتسمية الحقل ونوعه (من قائمة بكل أنواع الحقول المتاحة مثل `TEXT` و`NUMBER` و`SELECT` و`RELATION` وغيرها)، ومعرّف `universalIdentifier` للكائن الهدف.

## مسار خرج مخصّص

استخدم العلم `--path` لوضع الملف المُولَّد في موقع مخصّص:

```bash filename="Terminal"
yarn searm dev:add logicFunction --path src/custom-folder
```
